### About the project:
Play a classic game of 9x9 sudoku in the browser!

<img width="1082" height="694" alt="Screenshot 2026-08-07 113210" src="https://github.com/user-attachments/assets/09a054f7-37e5-4719-91fc-217e51db663e" />

### Features:
Main features include:
- Inputting numbers through the keyboard or the on-screen buttons
- Timer for comparing personal best times
- Hint button to automatically solve one random cell
- 3 difficulties (easy, medium, hard)
- Pencil marking (note taking inside cells)
- Automatic puzzle solver if you give up
- Inputted numbers are highlighted green if valid and red if invalid (a cell is not necessarily correct if highlighted green)
- Cells related to the selected cell are highlighted in a light shade.

### How it was made:
This project was made with HTML, CSS, and JS.
I've played many variants of sudoku for a long time, which inspired me to make it for myself.
The most difficult part of the project for me was implementing the pencil marking (taking notes).
There were a lot of edge cases and bugs I had to fix along the way, but in the end it all came together.
